- 2026-11-15: Validate archive metadata on both the source and generated row, then refuse file removal unless the full index is consistent; deleting a current Git file does not erase its history.

- 2026-11-15: A generated index must validate both missing source files and orphan documents so removing a module cannot silently leave stale content.

- 2026-11-15: A structurally valid import can still repeat generic text or flatten code; curate each language and require labelled depth, concise speaking points and question-specific answers in validation.

- 2026-11-15: Keep interview-prep content in a separate validated collection rather than adding it to the existing knowledge-base index contract.

- 2026-11-10: Queue producers must fail within a request budget when Redis is unavailable, while cache clients must keep bounded reconnection enabled so readiness can recover without restarting the API; verify both on one disposable process.

- 2026-11-10: A follow-up must extend the same teaching API and align its commands with measured IDs/states; separate observed local lab behavior from illustrative workflow, migration and telemetry.

- 2026-10-31: A large task skipped its plan/spec step; write a plan, and add a spec in `docs/specs/` for big tasks, before coding.
