Process

How I migrate a frontend

A strangler path: keep shipping while the old tree is replaced branch by branch.

Migrate in slices

Ship one route at a time. The old app stays up until the last page moves.

Test the contract

Playwright against the API, not the pixels. UI can change; the contract cannot.

Server state ≠ UI

TanStack Query (or Pinia) owns the server cache. Components own the view.

Write it down

Chose / Over / Because. The next person should not have to ask Slack.
